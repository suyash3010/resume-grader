PROJECT: Resume Grader
TYPE: Serverless Flask Application

STATUS: Ready for Production

================================================================================
QUICK START
================================================================================

Local Testing:
  1. echo "OPENAI_API_KEY=sk-proj-YOUR-KEY" > .env
  2. python3 app.py
  3. Visit http://localhost:5000

AWS Deployment:
  1. sam build
  2. sam deploy --stack-name resume-grader-httpapi \
     --parameter-overrides OpenAIApiKey="sk-proj-YOUR-KEY"

Get Endpoint:
  aws cloudformation describe-stacks --stack-name resume-grader-httpapi \
  --query 'Stacks[0].Outputs[0].OutputValue'

================================================================================
ARCHITECTURE
================================================================================

Frontend:
  - Modern HTML5 with gradient design
  - Responsive CSS (Tailwind-inspired)
  - Vanilla JavaScript (no framework dependencies)
  - File upload with drag-and-drop
  - Real-time status updates

Backend:
  - Flask 3.0.0 microframework
  - AWS Lambda handler (mangum 0.17.0 ASGI adapter)
  - Asynchronous WSGI conversion (asgiref 3.7.2)

AI/ML:
  - OpenAI GPT-4o model
  - Structured JSON output parsing
  - Customizable rubric/job description

File Processing:
  - PDF: pypdfium2 4.30.0
  - DOCX: python-docx 1.0.1
  - TXT: native Python
  - Max size: 50 MB per file

Data Export:
  - Excel/XLSX: openpyxl 3.1.2 + pandas 2.1.4
  - Sorted by mandatory requirement + score
  - Downloadable filename: shortlist_YYYYMMDD_HHMMSS.xlsx

Infrastructure:
  - AWS Lambda (Python 3.11, 1024 MB memory, 300s timeout)
  - AWS API Gateway v2 (HttpApi)
  - AWS CloudFormation (IaC)
  - CloudWatch Logs integration

================================================================================
TROUBLESHOOTING
================================================================================

Issue: API Key Not Configured
  Solution: Check .env exists and OPENAI_API_KEY is set
  Command: echo $OPENAI_API_KEY
  Lambda: Pass via --parameter-overrides

Issue: 403 Unauthorized from OpenAI
  Solution: Verify paid account, active billing, gpt-4o access
  Test: python3 test_openai.py
  Check: https://platform.openai.com/account

Issue: Stack Creation Fails
  Solution: Delete and redeploy
  Commands:
    aws cloudformation delete-stack --stack-name resume-grader-httpapi
    aws cloudformation wait stack-delete-complete --stack-name resume-grader-httpapi
    sam deploy --stack-name resume-grader-httpapi --parameter-overrides ...

Issue: Download Not Working
  Solution: Clear browser cache, try incognito, check console (F12)
  Check: Browser console for JavaScript errors

Issue: Resume Processing Timeout
  Solution: Increase Lambda timeout in template.yaml (max 900s)
  Or: Process in smaller batches

Issue: High AWS Bills
  Solution: Check Lambda invocation count, consider batch limits

IMPORTANT NOTES

Security:
  - API key handled via environment variables
  - No API keys in code/git
  - Use .env locally, CloudFormation params in production
  - Recommend IP whitelisting if private use
  - Consider API authentication for production

Costs:
  - AWS charges per invocation + duration
  - OpenAI charges per API call + tokens
  - Set up billing alerts in AWS Console
  - Monitor OpenAI usage at https://platform.openai.com/account/billing

Rate Limiting:
  - 0.3s sleep between resumespacing to avoid OpenAI rate limits
  - Add AWS API throttling for production traffic

Limitations:
  - Max 50 MB file size per upload
  - Max 300s Lambda timeout (adjust in template.yaml)
  - Single file extraction may fail (error handling included)
  - Results stored in memory (not persisted)
